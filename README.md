# To-do List

Lista de tarefas com tema claro e escuro, feita no curso da [Refatorando](https://plataforma.refatorando.com/).

## Funcionalidades

- Adicionar tarefas (digite e aperte **Enter**)
- Marcar como concluída (o texto fica riscado)
- Excluir tarefas (botão **×**)
- Filtros: Todos, Ativos e Concluídos
- Contador de itens restantes
- Botão para limpar as concluídas
- Alternar entre tema claro e escuro
- Tarefas e tema ficam salvos no navegador (`localStorage`)
- Layout responsivo para celular

## Como abrir

Abra o `index.html` no navegador ou use a extensão **Live Server** do VS Code.

## Tecnologias

- HTML5 semântico (lista, formulário e labels acessíveis)
- CSS3 com variáveis, Flexbox e media queries
- JavaScript puro
